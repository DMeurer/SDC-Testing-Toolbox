# Feature ideas

Ideas noted for later. Nothing here is planned or designed yet.

## Export My device as a starter provider script

Turn the device built in the window into a small, runnable sdc11073 provider script: it loads
the exported MDIB file, starts the provider and updates one metric in a loop, with comments
that say what each step does. It would bridge the toolbox and a beginner's own first device,
so they do not have to rebuild in code what they already put together in the GUI.

## A click-through tutorial on first start

When someone starts the toolbox for the first time, a guided tutorial walks them through it
step by step: it points at the part of the window to use next and says what to do there (for
example: start a device, open the Network tab, scan, connect, change a value), so a beginner
knows where to begin without reading the README first.
