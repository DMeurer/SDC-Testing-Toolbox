# Keyboard shortcuts

| Keys | Does |
|---|---|
| Ctrl+O | Import config… |
| Ctrl+S | Export config… |
| Ctrl+K | Check MDIB… |
| Ctrl+Q | Exit |
| F8 | Split view on or off |
| F9 | Cards or tables |
| F11 | Fullscreen on or off |
| Alt | shows the menu bar while *Always show menu bar* is off |
| Ctrl+W | closes the current connection (inside the Network tab) |
| Ctrl+Enter | sends a multi-line text card |
| Enter | sends a single-line text card |
