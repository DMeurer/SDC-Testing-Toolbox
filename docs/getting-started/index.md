# Getting started

Three short pages take you from nothing to two devices that talk to each other:

1. [Installation](install.md): a ready-made build for Windows or Linux, or the source code.
2. [Your first device](first-steps.md): start the toolbox twice, build a device in one, connect
   to it from the other, change a value and raise an alarm.
3. [SDC in ten minutes](sdc-basics.md): the ideas behind what you just saw: providers and
   consumers, the MDIB, metrics, operations, alarms, contexts and discovery.

If you already know SDC, the second page is enough; the [User guide](../user-guide/) explains the
rest when you need it.
